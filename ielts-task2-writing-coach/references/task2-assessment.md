# Task 2 assessment guide

Use this reference to calibrate feedback, not to reproduce official examiner materials or imply an official score.

## Question-type routing

| Type | Required response |
|---|---|
| Opinion | State and defend a clear view; address the proposition rather than merely describing it. |
| Discussion | Explain both views and answer any request for the writer's own view. |
| Advantages/disadvantages | Address both sides; only evaluate whether advantages outweigh disadvantages if explicitly asked. |
| Problem/solution | Identify relevant causes or problems and propose feasible, explained solutions. |
| Two-part question | Answer each question directly and develop each response sufficiently. |

## Four feedback dimensions

| Dimension | Look for | Avoid |
|---|---|---|
| Task Response (TR) | Direct coverage of every part, a clear position, relevant and sufficiently developed ideas | Treating length, fixed paragraph count, or examples alone as proof of quality |
| Coherence and Cohesion (CC) | Logical progression within and between paragraphs, purposeful referencing, non-mechanical linking | Counting connectors or demanding a template |
| Lexical Resource (LR) | Precise meaning, appropriate collocation and register, enough flexibility to avoid damaging repetition | Replacing simple accurate words with obscure synonyms |
| Grammatical Range and Accuracy (GRA) | Controlled range of sentence forms and error patterns that do not impede communication | Over-crediting complexity when clauses are unreliable |

## Target-band calibration

These are practical coaching targets, not official scoring rules.

| Target | Coaching focus |
|---|---|
| 6.5 | Make every response obligation clear; build relevant body paragraphs; remove frequent errors that distract or obscure meaning. |
| 7.0 | Sustain a clear position, explain claims rather than list them, use natural cohesion, and show flexible language with mostly reliable accuracy. |
| 7.5 | Develop ideas with precision and depth, control paragraph movement, choose words and structures accurately, and eliminate recurring slips. |
| 8.0 | Maintain nuanced, rigorous reasoning and consistently natural, accurate language. Identify remaining micro-level issues without pretending perfection is required. |

## Reporting an estimate

Report a band estimate only after noting whether the prompt is available and the response seems complete. Use “estimated” and allow a range where evidence is limited. An exact-looking score must never replace the explanation of why the learner would gain or lose marks.
